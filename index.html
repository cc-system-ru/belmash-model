01 — Логика модели

Почему именно такая архитектура

Изменение системы мотивации потребовало пересмотра самой структуры управления: корректная мотивация невозможна без чёткого распределения ролей, ЦКП и зон ответственности.

01

Ключевая проблема AS-IS

Нет единого центра ответственности за результат. Коммерческие каналы жили по разной логике управления. Премирование заменялось выполнением задач. Роли описывались через перечень действий, а не через конечный продукт. Входящий поток оседал стихийно — без квалификации и маршрутизации.

02

Принцип TO-BE

Каждая роль — один ЦКП. У каждого канала — свой владелец. Продающие и сопровождающие функции разведены. Входящий поток маршрутизируется по типу клиента. Мотивация привязана к результату, а не к активности.

03

Запрос на плоскую модель

Максимум 2 уровня иерархии. Все руководители функциональных групп отчитываются ГД напрямую ежемесячно по единому шаблону: план / факт / что мешает / что нужно.

04

Решение: два слоя управления

Слой 1 — функциональные группы с прямым подчинением ГД. Слой 2 — четыре комитета для решений на стыке групп: командный показатель + командный бонус.

Слой 1 — Оргструктура

  • 13 функциональных групп напрямую к ГД без промежуточных уровней
  • Ежемесячные письменные отчёты каждого руководителя
  • Мотивация руководителя — от результата его функциональной группы
  • Каждая роль имеет ЦКП — конечный продукт, а не набор действий

Слой 2 — Комитеты

  • Периодические встречи для решений на стыке нескольких групп
  • Комитет не управляет постоянно — собрались, решили, разошлись
  • 4 комитета: коммерческий, ассортиментный, операционный, финансовый
  • Командный бонус — от результата комитета

04 — Комитеты

Четыре комитета — второй слой управления

Комитет — не уровень иерархии, а периодическая рабочая группа для решений на стыке нескольких функциональных групп. У каждого один сквозной показатель, которого ни одна группа не достигает в одиночку.

Конверсия входящего потока в выручку

Все обращения по всем цифровым точкам входа → закрытые сделки. Без трафика от Развития — мало лидов. Без квалификации e-com — потери на входе. Без правильной маршрутизации — B2B не разрабатывается в опте.

Общее выполнение плана по всем каналам

Суммарный план e-com + опт + тендер. Ни один канал не выполнит его в одиночку — общий бонус только при выполнении общего плана.

Постоянная повестка

  • Разбор конфликтов по распределению клиентской базы e-com ↔ опт
  • Исполнение регламента передачи B2B-клиентов: разбор отклонений
  • Квартальное согласование коммерческих планов по каналам

05 — Регулярный менеджмент

Ритм управления компанией

Два слоя управления — два ритма. Функциональные группы: частый операционный контакт. Комитеты: плановые встречи для кросс-функциональных решений. Единый дашборд с показателями всех групп ведётся постоянно.

Еженедельно

Внутри каждой группы

  • Планёрка внутри группы (30 мин)
  • Обновление общего дашборда — все показатели видны всем
  • Синхронизация e-com ↔ опт по клиентским передачам
  • Разбор текущих блокеров
1×/мес
